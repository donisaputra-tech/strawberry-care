
# 🍓 Strawberry Care
### Strawberry Leaf Disease Detection Using CNN and MobileNetV2

Strawberry Care is a web-based application designed to classify strawberry leaf conditions using deep learning. The project combines a web interface with a CNN image classification model based on MobileNetV2.

## 📌 Project Overview

This project focuses on classifying strawberry leaf images into three classes:

- Angular Leaf Spot
- Healthy
- Leaf Scorch

## 🎯 Objectives

- Develop a web-based interface for strawberry leaf image classification.
- Apply transfer learning with MobileNetV2.
- Display prediction results to help users understand the predicted leaf condition.

## 🛠️ Technologies

- **Programming Languages:** Python, PHP, JavaScript
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Flask, PHP
